# 병원 상태·질병 검색 근거 수집

## 요청 요약

- 네이버 공개 검색 결과를 활용해 탈피, 배변, 산란과 앱의 전체 질병 항목에 대한 병원 데이터를 한 번 수집한다.
- 수집 결과는 화면에 반영하지 않고 데이터값으로만 보관한다.

## 분석·판단 이유

- 네이버 플레이스 방문자 리뷰 전체를 비공식 크롤링하는 방식은 접근 제한과 안정성 문제가 있다.
- 프로젝트에 설정된 네이버 공식 검색 API를 사용해 블로그·카페 공개 검색 결과의 제목, 짧은 요약, 원문 URL만 수집한다.
- 검색 노출은 의료 품질이나 치료 성공률을 의미하지 않으므로 추천 순위가 아니라 추천 계산 전 근거 데이터로 구분한다.

## 수정 파일

- `scripts/collect-hospital-condition-evidence.mjs`
- `package.json`
- `data/research/hospital-condition-evidence.json`

## 핵심 변경 내용

- 앱에 등록된 병원 43곳을 병원명, 지역, 파충류 키워드로 검색해 기본 공개 근거를 확인한다.
- 탈피, 배변, 산란과 병원 리뷰 작성 화면의 진단 18개를 합친 21개 항목을 파충류·도마뱀·거북이·뱀 검색어로 조사한다.
- 검색 문서에서 병원명을 추출해 앱 병원과 연결하고, 앱 목록 밖 병원 근거도 전역 근거에 보관한다.
- 근거가 확인되지 않은 항목은 `insufficient_evidence`로 저장한다.
- 데이터에는 화면 미연결 상태, 수집 시각, 출처 구분, 원문 링크, 검색 오류를 함께 기록한다.

## 검증 결과

- 네이버 공식 검색 API 요청 254건이 오류 없이 완료되었다.
- 43개 병원과 21개 항목 구조가 모두 생성되었고, 전역 공개 검색 근거 825건을 저장했다.
- 데이터는 `screenIntegrated: false` 상태이며 화면 코드에서 불러오지 않는다.

## 남은 작업

- 실제 추천에 사용하기 전 병원 자체 홍보 글과 보호자 후기를 분리하고, 원문 표본을 사람이 검토해야 한다.
