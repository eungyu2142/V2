# account/login 작업 기록

## 역할

로그인, 회원가입, 로그아웃, 계정 생성, 계정 삭제 등 계정 관련 작업을 기록한다.

## 기준

- 계정 기능은 프로필의 계정 관리와 연결되어야 한다.
- 로그인 상태에 따라 좋아요, 임시저장, 내가 쓴 글/리뷰, 반려동물 기록이 자연스럽게 연결되어야 한다.

## 2026-07-03 기록

### 문제 인식

사용자는 account/login 범주를 별도 기록 파일로 분리하길 요청했다.

### 해결 과정

`docs/project-records/account-login.md`를 만들고 로그인, 회원가입, 로그아웃, 계정 생성 기록을 이 파일에 누적하도록 했다.

### 완료 기록

account/login 작업 기록 파일을 생성했다.
## 2026-09-03 신고 누적 계정·설치 기기 차단

- 요청 요약: Q&A 욕설 신고 5회 누적 계정은 자동 삭제하고 해당 휴대폰의 재접근을 차단한다.
- 분석·판단 이유: 브라우저의 하드웨어 지문은 개인정보 침해와 오탐 위험이 있어 수집하지 않고, 앱 설치 시 생성한 무작위 ID의 SHA-256 해시를 계정에 연결한다.
- 수정 파일: `src/App.tsx`, `src/lib/qnaModeration.ts`, `supabase/migrations/202609030001_qna_profanity_reports_and_device_bans.sql`
- 핵심 변경 내용: 인증된 사용자의 설치 해시를 등록하고 앱 시작 시 차단 여부를 확인한다. 5명의 서로 다른 신고자가 서버 검증을 통과하면 대상 Auth 계정 삭제 전에 연결된 설치 해시를 차단 목록에 보존한다.
- 검증 결과: TypeScript 검사와 관련 파일 ESLint를 통과했다.
- 남은 작업: 저장소·브라우저 데이터를 삭제하거나 다른 브라우저를 쓰면 설치 식별자가 바뀔 수 있으므로 네이티브 기기 수준의 영구 차단은 별도 앱 기능이 필요하다.
## 2026-09-03 자동 경고 기반 계정 제재로 변경

- 요청 요약: 사용자 신고 5회가 아니라 서버가 감지한 욕설 경고 5회에 계정을 제재한다.
- 분석·판단 이유: 신고자 수에 따라 결과가 달라지는 구조보다 작성 콘텐츠 자체를 기준으로 누적하는 편이 요청한 자동 처리에 맞다.
- 수정 파일: `src/lib/qnaModeration.ts`, `src/components/profile/ProfileScreen.tsx`, `supabase/migrations/202609030001_qna_profanity_reports_and_device_bans.sql`
- 핵심 변경 내용: 서버 경고 건수를 설정 화면에서 조회하는 RPC를 추가하고, 5회 누적 시 Auth 계정 삭제 전에 연결된 설치 해시를 차단 목록에 저장한다.
- 검증 결과: TypeScript 검사와 관련 파일 ESLint를 통과했다.
- 남은 작업: 원격 Supabase 마이그레이션 적용이 필요하다.
