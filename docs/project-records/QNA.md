# Q&A 작업 기록

## 기능 범위

- 특수동물 질문 목록과 검색
- 건강·증상, 사육·관리 카테고리
- 질문 작성, 수정, 삭제, 해결 상태 변경
- 댓글 작성과 답변 채택
- 반려동물 정보와 다이어리 기록 첨부
- 병원 정보 첨부
- 작성자 프로필 이미지 표시

## 데이터 흐름

- 질문 데이터는 `community_posts` 테이블과 연결한다.
- 댓글 데이터는 `post_comments` 테이블과 연결한다.
- 작성자만 질문 수정·삭제와 해결 상태 변경을 수행한다.
- 기록 첨부는 선택한 반려동물의 다이어리 데이터와 연결한다.

## UI 원칙

- 화면 표기는 `Q&A`를 사용한다.
- 목록에서는 제목, 동물 정보, 상태, 댓글 수를 우선 표시한다.
- 질문 상세에서는 본문, 첨부 기록, 댓글 순서로 보여준다.
- 모바일에서는 검색과 필터를 가로 스크롤 또는 바텀시트로 제공한다.
- 작성 화면은 단계형 흐름과 게이지를 사용한다.

## 2026-07-24 문서 정리

기존 CP949/UTF-8 변환 오류로 깨진 기록을 제거하고, Q&A 기능·데이터 흐름·UI 규칙을 UTF-8 한국어 문서로 다시 정리했다. 앞으로 날짜별 파일을 만들지 않고 이 문서에 내용을 누적한다.
